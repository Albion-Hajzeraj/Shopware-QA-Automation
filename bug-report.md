# Bug Report

## Title
Prices include VAT section displays Lorem Ipsum placeholder text

## Environment
Browser: Chrome  
OS: Windows 10/11  
URL: https://www.shopware6-demo.development-s25.com/

## Steps to Reproduce

1. Open a product page
2. Locate and click the "Prices include VAT" information
3. Expand/open the details section

## Expected Result

The section should display meaningful tax/shipping information.

## Actual Result

The section displays Lorem Ipsum placeholder text.

## Severity
Low

## Justification

This issue does not block checkout or purchasing functionality, but placeholder text appears unfinished and may reduce professionalism or confuse users.
