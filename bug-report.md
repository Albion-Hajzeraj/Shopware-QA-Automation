# Bug Report

## Title
Prices include VAT section displays Lorem Ipsum placeholder text

## Environment
Browser: Chrome  
OS: Windows 10/11  
URL: https://www.shopware6-demo.development-s25.com/

## Steps to Reproduce

1. Open a product page
2. Locate and click the "Prices include VAT" information
3. Expand/open the details section

## Expected Result

The section should display meaningful tax/shipping information.

## Actual Result

The section displays Lorem Ipsum placeholder text.

## Severity
Low

## Justification

This issue does not block checkout or purchasing functionality, but placeholder text appears unfinished and may reduce professionalism or confuse users.

## Title
Language switches between German and English when navigating to the checkout page

## Environment
Browser: Chrome  
OS: Windows 10/11  
URL: https://www.shopware6-demo.development-s25.com/checkout/

## Steps to Reproduce

1. Open the Shopware site
2. Add a product to the cart if necessary
3. Navigate to the checkout page
4. Move to another page or refresh the checkout page
5. Observe whether the page content switches language

## Expected Result

The checkout page and site navigation should remain consistently in the selected language.

## Actual Result

The page may display German text and then switch back to English, or it may remain fully German unexpectedly.

## Severity
Medium

## Justification

Intermittent language switching in checkout or navigation can confuse users, undermine trust, and disrupt the purchase flow.
